# ForestSwarm Multi-Agent Orchestration - Phase 3

## Overview
ForestSwarm provides multi-agent orchestration for real estate deal lifecycle management, with:
- Agent tree definitions for deal lifecycle
- Cowork Copilot - AI assistant for agents
- "Morning Read" - Daily briefing for agents
- "What Needs You Now" - Priority task queue
- Multi-agent coordination for deal progression

## Directory Structure
```
packages/forestswarm/
├── README.md
├── agent-tree.ts          # Deal lifecycle agent tree
├── cowork-copilot.ts      # AI assistant for agents
├── queues.ts              # Task queues (Morning Read, What Needs You Now)
├── orchestrator.ts        # Agent orchestration logic
└── index.ts               # ForestSwarm entry point
```
